# Γερμανικά με Στυλ

Premium landing page για μαθήματα Γερμανικών & Αγγλικών από τη Βιργινία Πανάκη.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Development

```bash
npm install
npm run dev
```

## Configuration

Ενημέρωσε το Facebook URL και άλλα στοιχεία επικοινωνίας στο `src/lib/config.ts`.

## Production

```bash
npm run build
npm start
```
